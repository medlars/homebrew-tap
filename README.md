# medlars/homebrew-tap

Homebrew formulae for [Vohux](https://vohux.com) tools.

```bash
brew tap medlars/tap
brew install verdictui
```

## Formulae

| Formula | Description |
|---|---|
| [`verdictui`](Formula/verdictui.rb) | SwiftUI verification engine — semantic verdicts instead of screenshots ([repo](https://github.com/medlars/verdictui)) |
