### `verdictui` — temporarily unavailable

SwiftUI verification engine — semantic verdicts instead of screenshots.

The `verdictui` formula has been withdrawn for the moment, and its repository is
private while some housekeeping is completed. `brew install verdictui` will not
resolve until it returns.

Nothing is wrong with the tool itself; this is a temporary state and the formula
will be restored, under a new version tag, once the repository is public again.
